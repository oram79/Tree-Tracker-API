# Binary Search Tree Backend API 

This is the backend component of the **Binary Search Tree (BST) Visualizer** application. Built with **Spring Boot**, it allows users to:

- Submit a list of numbers to create a binary search tree.
- Retrieve all previously saved trees.
- Optionally generate and return a balanced BST (bonus challenge).
- Store and fetch BST data via a connected SQL database.

## 📦 Technologies Used

- Java 17
- Spring Boot 3.x
- Spring Data JPA
- MySQL Database
- Maven
- JUnit 5
